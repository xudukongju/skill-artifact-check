## Catch stale Skill packages before upload

Skill Artifact Check compares a ZIP/.skill release or installed folder with the source you actually edited. It reports changed, missing and extra payload files without printing their contents.

- Python 3.10+, standard library only at runtime.
- Offline, read-only; no extraction or skill execution.
- Directory ↔ ZIP and ZIP ↔ ZIP comparisons, including binary assets.
- Archive/layout checks and JSON output for CI gates.
- 34 regression tests; release publication is gated on tests, wheel builds and installed-CLI smoke checks on Linux, macOS and Windows with Python 3.10 and 3.12.

Download the source ZIP and run `python3 skill_artifact_check.py YOUR.skill --source YOUR-SKILL-FOLDER`, or install the wheel with `python3 -m pip install PATH-TO-WHEEL`.

This alpha checks payload parity and selected layout rules. It does not validate full YAML metadata, certify skill security, or prove a running client loaded the new files. See the README for exact limits and related tools.

Implementation, tests and documentation were primarily authored with Codex. Feedback with small non-private reproductions is welcome.
